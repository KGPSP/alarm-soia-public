# Zgłaszanie problemów bezpieczeństwa

Nie publikuj danych osobowych, tokenów powiadomień, szczegółów podatności przed ich usunięciem ani
informacji operacyjnych służb w publicznych Issues.

Zgłoszenie bezpieczeństwa wyślij na `informacje@kg.straz.gov.pl` z tematem:

`ALARM.SOIA — bezpieczeństwo`

Podaj wersję aplikacji i systemu, model telefonu, zwięzłe kroki odtworzenia oraz oczekiwane
i faktyczne zachowanie. Testuj wyłącznie na własnych urządzeniach; nie próbuj publikować ostrzeżeń,
podszywać się pod służby ani zakłócać działania serwera `alarm.soia.info` — to element systemu
ostrzegania ludności. Nie dołączaj niezredagowanych zrzutów ekranu.

Publiczne repozytorium zawiera tylko kod statycznej witryny i przygotowane materiały sklepowe.
Kod aplikacji mobilnej nie jest publiczny.
